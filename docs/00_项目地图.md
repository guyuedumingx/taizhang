## 项目一句话定位

**企业内部台账数据管理平台**。用户可自定义台账模板（含动态字段），按模板创建台账，提交后走通用审批流，过程中自动记录审计日志。技术栈 Python 3.11 + FastAPI + SQLAlchemy + PostgreSQL/Oracle + React + Ant Design 5。

## 关键技术事实（必须记住）

### 1. 密码哈希算法
**bcrypt**（`passlib.context.CryptContext(schemes=["bcrypt"])`）

⚠️ 接入数字画像时，数字画像用 **PBKDF2-SHA256**，**算法不一致必须统一**（要么两边改 bcrypt，要么强制用户重置密码）。

### 2. EHR 号规则
**7 位数字字符串**（`VARCHAR(7)`，`pattern=r'^\d{7}$'`）

数字画像是 `VARCHAR(50)`，必须改为 7 位数字（或者迁移时强制转换）。

### 3. 数据库支持
**SQLite（开发） + Oracle（生产）**，通过环境变量 `DATABASE_TYPE=oracle` 切换。

- 连接池针对 Oracle 优化：`pool_size=20, max_overflow=20, pool_recycle=1800`
- Oracle 连接串：`oracle+cx_oracle://user:pwd@host:port/?service_name=xxx`

### 4. JWT 配置
- 算法：HS256
- 过期：8 天（`60*24*8` 分钟）
- Payload：`{sub: str(user.id), roles: [...]}`，**不含** ehr_id、username
- 前端 token 来源：`POST /api/v1/auth/login` → 返回 `{access_token, ...}`

### 5. 密码策略
- **90 天过期**：超过 90 天未改密码会标记 `password_expired=True`，前端弹窗强制改
- `last_password_change` 字段记录上次改密时间

### 6. 权限模型
- **Casbin RBAC**：`rbac_model.conf` + 动态策略（`policy.csv` 存在数据库）
- 角色通过 `add_role_for_user(user_id, role_name)` 分配
- 权限检查：`check_permission(user_id, resource, action)`
- **is_superuser=True 直接绕过所有检查**
- 默认新用户角色：`user`

### 7. 通用审批引擎（4 级抽象）
```
Workflow（流程定义）
  └─ WorkflowNode（节点：开始/审批/结束）
        └─ WorkflowInstance（每次台账提交生成一个实例）
              └─ WorkflowInstanceNode（每个节点的状态）
```
- **多审批人支持**：节点的 `approvers` 表 + `multi_approve_type`（`any`/`all`）
- **驳回可配置**：节点的 `reject_to_node_id` 指向驳回后跳转的节点
- ⚠️ **WorkflowInstance 与 Ledger 是 1:1**（`ledger_id` 唯一约束）

### 8. 动态字段机制
- `Template` 包含多个 `Field`（字段定义）
- `Ledger` 包含多个 `FieldValue`（字段值）
- 字段类型：`input/textarea/select/date/number`
- 关键字段：`is_key_field=True` 用于自动填充

### 9. 自动填充机制
- `Template.auto_fill_config` 是 JSON 配置
- 触发器配置存在 `auto_fill_trigger_configs` 表（按 `field_name` 关联）
- 流程：用户输入关键字段 → debounce 去抖 → 调用外部 API → 按 field_mapping 填值

### 10. 日志分两类
- **SystemLog**：所有操作日志（`module/action/resource_type/resource_id`）
- **AuditLog**：审批相关审计（`ledger_id/workflow_instance_id/status_before/after`）

## 关键术语表

| 术语 | 含义 |
|---|---|
| 台账（Ledger） | 一条业务记录，关联模板+字段值+工作流实例 |
| 模板（Template） | 台账的结构定义，包含字段列表 |
| 字段（Field） | 模板中的单个字段定义（类型、是否必填） |
| 字段值（FieldValue） | 台账中某个字段的实际填值 |
| 工作流（Workflow） | 审批流程定义（多个节点） |
| 节点（WorkflowNode） | 工作流中的一个审批环节 |
| 工作流实例（WorkflowInstance） | 某次台账提交触发的工作流 |
| 节点实例（WorkflowInstanceNode） | 工作流实例中每个节点的状态 |
| EHR 号 | 7 位数字员工唯一标识 |
| 团队（Team） | 用户分组，可设组长 |
| 角色（Role） | 通过 Casbin 管理的 RBAC 角色 |
| 资源（Resource） | 权限管理的对象（如 `user/ledger/workflow`） |
| 操作（Action） | 资源上的动作（如 `view/create/update/delete`） |
| 自动填充（AutoFill） | 关键字段填值后自动调用外部 API 填其他字段 |
| 系统日志（SystemLog） | 所有操作的日志 |
| 审计日志（AuditLog） | 审批状态变更的日志 |

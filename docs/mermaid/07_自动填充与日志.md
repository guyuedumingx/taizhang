# 自动填充配置 + 日志模块

## 7.1 自动填充模块类关系

```mermaid
classDiagram
    class AutoFillTriggerConfig {
        <<自动填充触发器配置>>
        +int id
        +string field_name UK "字段名"
        +string api_url "外部 API 地址"
        +json headers "HTTP 头"
        +int timeout
        +int retry_times
        +bool enabled
        +text description
    }

    class Template {
        +int id
        +json auto_fill_config<br/>"enabled/key_field_name/trigger_on<br/>/debounce_ms/field_mapping"
    }

    class AutoFillTriggerLoader {
        <<core/auto_fill_trigger_loader.py>>
        +load_all() "启动时加载"
        +get_config(field_name)
    }

    class AutoFillExternalService {
        <<services/auto_fill_external_service.py>>
        +call_external_api(config, value)
    }

    AutoFillTriggerConfig "1" --> "0..*" Template : 字段名关联
    AutoFillTriggerLoader --> AutoFillTriggerConfig : 启动时加载
    Template --> AutoFillExternalService : 触发时调用
```

## 7.2 自动填充触发流程

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant Form as LedgerForm.tsx
    participant LS as ledger_service
    participant AFE as auto_fill_external_service
    participant Loader as auto_fill_trigger_loader
    participant ExtAPI as 外部 HTTP API

    User->>Form: 在关键字段输入内容 (例: 身份证号)
    Form->>Form: debounce_ms 去抖<br/>(避免每次按键都触发)
    Form->>LS: 请求自动填充
    LS->>Loader: get_config(field_name="id_card")
    Loader-->>LS: AutoFillTriggerConfig {api_url, headers, ...}

    alt enabled=true
        LS->>AFE: call_external_api(config, value)
        AFE->>ExtAPI: HTTP POST/GET (带 headers)
        alt 成功
            ExtAPI-->>AFE: 响应数据 (姓名/地址/...)
            AFE->>AFE: 按 field_mapping 映射字段
            AFE-->>LS: 填充数据
            LS-->>Form: 自动填入其他字段
            Form-->>User: 字段已自动填充
        else 失败 retry_times 内
            AFE->>ExtAPI: 重试 (最多 retry_times)
        else 重试耗尽
            AFE-->>LS: 抛出异常
            LS-->>Form: 字段保持原样 (降级)
        end
    else enabled=false
        LS-->>Form: 跳过自动填充
    end
```

## 7.4 日志记录流程

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant API as 任意 API endpoint
    participant SVC as 对应 service
    participant LogSvc as log_service
    participant DB as PostgreSQL

    User->>API: 发起请求 (例: 提交台账)
    API->>SVC: 业务处理
    SVC->>SVC: 操作数据库
    SVC->>LogSvc: log_operation()<br/>(user_id, module, action, resource)
    LogSvc->>DB: INSERT system_logs
    DB-->>LogSvc: OK

    alt 是审批/提交类操作
        SVC->>LogSvc: log_audit()<br/>(user_id, ledger_id, action, status_before/after)
        LogSvc->>DB: INSERT audit_logs
    end

    SVC-->>API: 业务结果
    API-->>User: 响应

    Note over User,DB: 异步日志(可能):<br/>SVC -.->|后台任务| LogSvc
```

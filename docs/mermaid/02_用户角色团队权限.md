## 2.2 鉴权流程（JWT + Casbin）

```mermaid
sequenceDiagram
    autonumber
    participant FE as 前端
    participant API as /auth/login
    participant Sec as core/security.py
    participant UserSvc as services/user_service.py
    participant Casbin as services/casbin_service.py
    participant DB as PostgreSQL

    FE->>API: POST /auth/login (username/ehr_id + password)
    API->>UserSvc: get_user_by_username_or_ehr_id()
    UserSvc->>DB: SELECT users WHERE username/ehr_id
    DB-->>UserSvc: User 对象
    UserSvc-->>API: User
    API->>Sec: verify_password(plain, hashed_password)
    Sec-->>API: True/False
    alt 验证通过
        API->>Casbin: get_roles_for_user(user_id)
        Casbin->>DB: SELECT policy.csv (Casbin)
        DB-->>Casbin: 角色列表
        Casbin-->>API: roles
        API->>Sec: create_access_token({sub, roles, ehr_id})
        Sec-->>API: JWT token
        API-->>FE: {access_token, user_info}
    else 验证失败
        API-->>FE: 401 Unauthorized
    end

    Note over FE,API: 后续请求带 Authorization: Bearer <token>

    FE->>API: GET /users/me (带 JWT)
    API->>Sec: decode_access_token()
    Sec-->>API: payload (sub, roles)
    API->>Casbin: check_permission(user_id, resource, action)
    CASBIN-->>API: True/False
    alt 有权限
        API-->>FE: 数据
    else 无权限
        API-->>FE: 403 Forbidden
    end
```

## 2.4 密码哈希算法（关键事实）

> ⚠️ **接入数字画像时必须注意**：台账用 **bcrypt**（`passlib.context.CryptContext(schemes=["bcrypt"])`），数字画像用 **PBKDF2-SHA256**。**算法不一致**，迁移用户时必须重哈希密码或强制重置。

# 模板管理（Template）模块

## 4.1 类关系

```mermaid
classDiagram
    class Template {
        +int id
        +string name
        +text description
        +string department
        +bool is_system "系统模板不可删"

    class Field {
        +int id
        +int template_id FK
        +string name

        +bool required

        +int id

        +bool is_active
    }

    Template "1" --> "0..*" Field : 包含字段
    Template "0..1" --> "0..1" Workflow : 绑定审批流
```

## 4.2 模板创建 → 字段配置 → 业务使用流程

```mermaid
sequenceDiagram
    autonumber
    participant Admin as 管理员
    participant T_EP as /templates
    participant F_EP as /templates/{id}/fields
    participant TS as template_service.py
    participant LS as ledger_service.py
    participant User as 用户

    Admin->>T_EP: POST /templates (name, department, workflow_id)
    T_EP->>TS: create_template()
    TS->>TS: 写入 templates
    TS-->>T_EP: Template
    T_EP-->>Admin: 201 Created

    Admin->>F_EP: POST /templates/{id}/fields<br/>(name, type, required, options)
    F_EP->>TS: add_field(template_id, field_data)
    TS->>TS: 写入 fields (order 自增)
    TS-->>F_EP: Field
    F_EP-->>Admin: 201 Created

    Note over Admin,User: 重复多次添加字段

    User->>LS: 创建台账 (template_id + data 按字段填值)
    LS->>TS: get_template_with_fields(template_id)
    TS-->>LS: Template + Fields
    LS->>LS: 校验 data 匹配字段定义<br/>写入 ledgers + field_values
    LS-->>User: Ledger
```

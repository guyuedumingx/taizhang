# 数据模型详细说明

> 共 14 张表，按业务模块分组。**这是改字段、加表时必读**。

---

## 模块总览

| # | 模块 | 表 | 关系复杂度 |
|---|---|---|---|
| 1 | 用户/团队/角色 | users / teams / roles | ⭐⭐ |
| 2 | 模板/字段 | templates / fields | ⭐⭐ |
| 3 | 台账 | ledgers / field_values | ⭐⭐⭐ |
| 4 | 工作流 | workflows / workflow_nodes / workflow_instances / workflow_instance_nodes / workflow_node_approvers | ⭐⭐⭐⭐ |
| 5 | 日志 | system_logs / audit_logs | ⭐ |
| 6 | 自动填充 | auto_fill_trigger_configs | ⭐ |

## 1. 用户/团队/角色

### `users`（用户）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK | |
| username | VARCHAR | UNIQUE, NOT NULL | 登录用户名 |
| **ehr_id** | VARCHAR(7) | UNIQUE, NOT NULL | **7 位数字 EHR 号** |
| hashed_password | VARCHAR | NOT NULL | **bcrypt 哈希** |
| name | VARCHAR | | 姓名 |
| department | VARCHAR | | 部门 |
| is_active | BOOLEAN | DEFAULT TRUE | ⚠️ 与 `is_disabled` 语义**反转** |
| is_superuser | BOOLEAN | DEFAULT FALSE | 超级管理员，绕过所有权限检查 |
| team_id | INT | FK→teams.id | |
| last_password_change | DATETIME | | 用于密码过期判断（90 天） |

**关系**：
- `team` → Team（`back_populates="members"`）
- `created_ledgers` / `updated_ledgers` → Ledger
- `workflow_nodes`（多对多，通过 workflow_node_approvers）

### `teams`（团队）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| name | VARCHAR | 团队名 |
| department | VARCHAR | 所属部门 |
| leader_id | INT | FK→users.id（**注意：没加 ForeignKey 约束**） |
| description | TEXT | |

**关系**：`members` / `leader` / `ledgers`

### `roles`（角色）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| name | VARCHAR | UNIQUE（角色名） |
| description | TEXT | |
| is_system | BOOLEAN | DEFAULT FALSE（系统内置不可删） |

**⚠️ 角色与权限的关系不在数据库表里**，存在 Casbin 的 `policy.csv`（动态加载到 SQL）。

## 2. 模板/字段

### `templates`（台账模板）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| name | VARCHAR | |
| description | TEXT | |
| department | VARCHAR | |
| is_system | BOOLEAN | DEFAULT FALSE |
| workflow_id | INT | FK→workflows.id（绑定审批流） |
| default_description | TEXT | |
| default_metadata | JSON | |

**关系**：`fields` / `ledgers` / `creator` / `updater`

| id | INTEGER | PK |
| template_id | INT | FK→templates.id **ON DELETE CASCADE** |
| name | VARCHAR | 字段标识（英文） |

| type | VARCHAR | **input/textarea/select/date/number** |
| required | BOOLEAN | DEFAULT FALSE |
| options | JSON | select 类型的选项 |
| default_value | VARCHAR | |
| order | INT | DEFAULT 0 |
| is_key_field | BOOLEAN | DEFAULT TRUE |

**关系**：`template` / `field_values`（cascade delete）

## 3. 台账

### `ledgers`（台账记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| name | VARCHAR | 台账名称 |
| description | TEXT | |
| **status** | VARCHAR | DEFAULT 'draft'：**draft / active / completed** |
| **approval_status** | VARCHAR | DEFAULT 'pending'：**pending / approved / rejected** |
| current_approver_id | INT | FK→users.id（当前审批人） |
| team_id | INT | FK→teams.id |
| template_id | INT | FK→templates.id |
| created_by_id | INT | FK→users.id NOT NULL |
| updated_by_id | INT | FK→users.id NOT NULL |
| data | JSON | 原始数据（备用） |
| created_at / updated_at / submitted_at / approved_at | DATETIME | |

**关系**：`team` / `template` / `creator` / `updater` / `current_approver` / `field_values`（cascade）/ `audit_logs`（cascade）

⚠️ `workflow_instance` 关系被注释了（避免循环引用），用 `ledger_id` 字段查 WorkflowInstance。

### `field_values`（字段值）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| ledger_id | INT | FK→ledgers.id **ON DELETE CASCADE** |
| field_id | INT | FK→fields.id **ON DELETE CASCADE** |
| value | TEXT | 值统一用 TEXT 存储 |

**关系**：`ledger` / `field`

## 4. 工作流（核心复杂度区）

### `workflows`（工作流定义）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| name | VARCHAR | |
| description | VARCHAR | |
| is_active | BOOLEAN | DEFAULT TRUE |
| created_by | INT | FK→users.id |

### `workflow_nodes`（工作流节点）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| workflow_id | INT | FK→workflows.id NOT NULL |
| name | VARCHAR | 节点名 |
| description | VARCHAR | |
| node_type | VARCHAR | **start / approval / end** 等 |
| approver_role_id | INT | FK→roles.id（审批人角色） |
| order_index | INT | NOT NULL（节点顺序） |
| is_final | BOOLEAN | DEFAULT FALSE |
| **reject_to_node_id** | INT | FK→workflow_nodes.id（驳回跳转） |
| **multi_approve_type** | VARCHAR | DEFAULT 'any'：**any / all** |

### `workflow_node_approvers`（节点-审批人多对多关联表）

```sql
workflow_node_id INTEGER FK→workflow_nodes.id (PK)
user_id          INTEGER FK→users.id (PK)
```

### `workflow_instances`（工作流实例）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| workflow_id | INT | FK→workflows.id |
| **ledger_id** | INT | UNIQUE（一对一，**未加外键避免循环引用**） |
| status | VARCHAR | DEFAULT 'active'：**active / completed / cancelled / rejected** |
| current_node_id | INT | 当前节点（**未加外键**） |
| created_by | INT | FK→users.id |
| created_at / updated_at / completed_at | DATETIME | |

### `workflow_instance_nodes`（节点实例状态）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | PK |
| workflow_instance_id | INT | FK→workflow_instances.id |
| workflow_node_id | INT | FK→workflow_nodes.id |
| status | VARCHAR | DEFAULT 'pending'：**pending / approved / rejected** |
| approver_id | INT | FK→users.id |
| comment | TEXT | |
| completed_at | DATETIME | |
| **approver_actions** | JSON | `[{"user_id, action, comment, timestamp}, ...]`（多人审批记录） |

## ⚠️ 字段命名不一致清单（接入数字画像时必须决策）

| 业务 | 数字画像 | 台账 |
|---|---|---|
| EHR 号字段 | `ehr_no VARCHAR(50)` | **`ehr_id VARCHAR(7)`** |
| 启用状态 | `is_disabled=False`（True=禁用） | **`is_active=True`**（语义**反转**） |
| 管理员 | `is_superadmin` | **`is_superuser`** |
| 密码字段 | `password_hash` | **`hashed_password`** |
| 组别字段 | `group_name` | **`department`** |
| 角色 | `role` 字段（枚举） | **Casbin RBAC** |

→ 详细映射见 `04_扩展点与集成指南.md`

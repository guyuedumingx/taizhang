## 3. 关键决策项

### 3.1 ⚠️ 集成指南 §5 雷区违规（必须修）

远程 `b6ba9b2` commit **修改了 `rbac_model.conf`**：
```
- m = g(r.sub, p.sub) && r.obj == p.obj && r.act == p.act
+ m = g(r.sub, p.sub) && (r.obj == p.obj || p.obj == "*") && (r.act == p.act || p.act == "*")
```

这**违反集成指南 §5 雷区 1（不改 rbac_model.conf）**。如果保留这个改动：
- 影响面：所有 taizhang 原有的 Casbin 策略都可能受影响（`p, admin, *, *` 这种通配策略生效）
- 与本地 P3 已有的工作冲突（本地策略不需要通配就 OK）

**建议**：合并时**回退 `rbac_model.conf` 改动**，保留远程其它改动。

### 3.2 字段命名（已在决策记录 §3 详细分析）

采纳远程 `ehr_no/group_name`（贴近 PRD 原版）。代价是本地 router/service 字段名 rename。

### 3.3 MyProfile.tsx 替换

替换本地 290 行（5 Tabs）为远程 346 行（13 区块 + Anchor）。Remote 的依赖：
- 调用 `getMyPortraitProfile()` (portraitProfiles.ts)
- 依赖 `PortraitProfileFull` type (types.ts)
- 依赖 `Anchor` 组件 (antd)

合并时**保留远程 MyProfile.tsx 原样**。

### 3.5 端点注册路径

| 来源 | 端点 | 路径 |
|---|---|---|
| 远程 | GET /me + GET /by-ehr/{ehr_no} | `/portrait/profiles` |
| 本地 | 全套 18 端点 + /me/permissions + /health | `/portrait/*` (聚合) |

冲突点：远程在 `app/portrait/router_profile.py`，本地在 `app/portrait/routers/{profiles,submissions,approvals,portrait}.py`。

合并策略：**保留远程的 `router_profile.py` + 本地的 `routers/profiles.py` 合并内容**（合并读路径 + 写路径）。最终在 `api.py`：
```python
from app.portrait.router_profile import router as portrait_profile_router  # 远程
from app.portrait.routers.portrait import portrait_router  # 本地聚合（含 submissions, approvals, health, me/permissions）
api_router.include_router(portrait_profile_router, prefix="/portrait/profiles", tags=["数字画像-档案"])
api_router.include_router(portrait_router, prefix="/portrait", tags=["数字画像"])
```

但**这会冲突**：聚合 router 路径 `/portrait`，里面又有 `/profiles` 子路由。FastAPI 不允许同 prefix 注册两次。

**正确做法**：远程的 router_profile.py 合并到本地 `routers/profiles.py`，删除远程 `router_profile.py`，统一走本地聚合 router。

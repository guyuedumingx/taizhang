## 1. 概述

### 1.1 背景

本需求文档描述台账管理系统中「特殊业务台账统计分析」功能的详细规格，涵盖多维度数据查询、统计分析与可视化展示能力，旨在帮助管理人员快速定位目标数据、多角度分析业务态势，并支持报表导出与报告编制。

### 1.2 术语说明

| 术语 | 说明 |
|------|------|
| 特殊业务台账 | 本系统中需进行统计分析的台账数据集合。可与现有「台账」概念等同，或通过台账类型/模板筛选出的子集。具体范围待业务确认。 |
| 台账类型 | 对应系统中的「模板」（Template），不同模板定义不同业务类型的台账结构。 |
| 流水号 | 台账的唯一流水标识，可能为台账 ID 或模板中某字段（如 `data.流水号`）。需在实现时与业务字段映射。 |
| 交易码 | 业务交易类型编码，通常为模板中的某个字段。需在实现时与业务字段映射。 |
| 分行 | 组织维度，可能对应「团队」（Team）或模板中的「分行」字段。 |
| 业务状态 | 可能对应台账的 `status`（草稿/活跃/完成）或 `approval_status`（待审批/已通过/已拒绝）。 |
| 视图 | 看板中的一组图表配置，可包含多个统计图表。 |
| 图表 | 单个统计结果的可视化展示（柱状图、折线图、饼图等）。 |

### 1.3 与现有系统的关系

- **台账**：沿用现有 Ledger 模型及 `data`（JSON）存储结构。
- **模板/字段**：沿用 Template、Field 模型，统计维度可基于模板字段动态配置。
- **团队**：沿用 Team 模型，用于「分行」等组织维度统计。
- **权限**：沿用现有权限体系，统计功能需配置相应权限点。

## 3. 详细需求规格

## 3.2 多维度统计分析功能

### 3.2.1 功能简述

- **数据查询**：提供模糊查询、精准查询和条件查询，支持通过：
  - 模糊搜索：台账名称、指定字段内容
  - 精准/条件筛选：流水号、交易码等条件
- **目标**：快速定位目标数据集，为后续统计与导出提供数据基础。

### 3.2.2 详细说明

#### 3.2.2.1 入口与界面

- **入口**：点击「特殊数据统计」菜单项，进入「特殊业务台账汇总」界面。
- **界面布局**：
  - 顶部：搜索框 + 筛选条件区
  - 中部：台账列表（表格形式）
  - 底部：分页（如需要）

#### 3.2.2.2 搜索功能

| 查询类型 | 说明 | 实现要点 |
|----------|------|----------|
| **模糊查询** | 在搜索框输入关键词，匹配台账名称或指定字段内容 | 支持对 `name`、`description` 及 `data` 中可搜索字段的模糊匹配（如 `ILIKE`） |
| **精准查询** | 按流水号、交易码等精确匹配 | 需支持按 `id` 或 `data` 中指定字段的精确匹配 |
| **条件查询** | 多条件组合筛选 | 支持台账类型、时间范围、业务状态、分行等组合 |

#### 3.2.2.3 筛选条件

| 筛选项 | 说明 | 数据来源 |
|--------|------|----------|
| 台账类型 | 按模板筛选 | Template 列表 |
| 相关字段 | 按模板内字段值筛选 | 根据所选模板动态加载 Field，支持对 `data` 中字段的筛选 |
| 流水号 | 精确或模糊匹配 | 需明确对应字段（如 `id` 或 `data.流水号`） |
| 交易码 | 精确或模糊匹配 | `data` 中对应字段 |
| 时间范围 | 创建时间、更新时间、提交时间等 | `created_at`、`updated_at`、`submitted_at` |
| 业务状态 | 草稿/活跃/完成、待审批/已通过/已拒绝 | `status`、`approval_status` |
| 分行/团队 | 按团队筛选 | `team_id` → Team |

#### 3.2.2.4 交互流程

1. 用户在搜索框输入关键词 → 触发模糊查询（可防抖）。
2. 用户选择/填写筛选条件 → 点击「查询」或「应用」→ 执行条件查询。
3. 列表展示筛选后的台账，支持排序、分页。
4. 支持「重置」清空所有筛选条件。

- [ ] 单次查询结果数量上限及分页策略。

## 3.3 数据展示功能

### 3.3.1 功能简述

- **统计维度配置**：预设分行、交易码、时间、业务状态等维度，支持多维度组合。
- **自定义统计**：支持管理人员新增统计维度与指标。
- **统计结果生成**：支持柱状图、折线图、饼图等，支持导出 Excel 报表。

### 3.3.2 详细说明

#### 3.3.2.1 入口与初始状态

- **入口**：点击「特殊业务数据看板」菜单项。
- **初始状态**：看板为空，提示「暂无视图，请创建视图」。

#### 3.3.2.2 视图管理

##### 创建视图

1. 点击「创建视图」。
2. 填写视图名称（必填）。
3. 可选：填写视图描述。
4. 点击「保存」→ 创建空视图，进入编辑模式。

##### 切换视图

- 视图左上角提供视图切换控件（下拉或 Tab）。
- 切换时加载对应视图下的所有图表配置并渲染。

##### 保存视图

- 视图及其包含的图表配置需持久化存储。
- 支持「保存」按钮，保存当前视图及其中所有图表。
- 新建/编辑图表后需提示保存，或支持自动保存。

##### 删除视图（待补充）

- 是否支持删除视图，以及删除时的确认与权限控制。

#### 3.3.2.3 图表管理

##### 添加图表

1. 在视图中点击「添加图表」。
2. 配置项：
   - **台账类型**：选择要统计的模板（可多选）。
   - **统计条件**：筛选条件（与 3.2.2 的筛选逻辑一致，如时间、状态、团队、字段等）。
   - **统计数据类型**：
     - 统计维度（分组依据）：如分行、交易码、时间、业务状态等。
     - 统计指标：如数量、金额汇总等。
     - 图表类型：柱状图、折线图、饼图等。
3. 填写完毕后，在视图中展示新图表预览。
4. 点击「保存」将图表配置写入当前视图。

##### 编辑图表

1. 在图表上右键 → 选择「编辑」。
2. 进入图表配置界面，修改统计条件、维度、指标、图表类型等。
3. 保存后更新图表展示。

##### 删除图表

1. 在图表上右键 → 选择「删除」。
2. 确认后从当前视图中移除该图表。
3. 需保存视图以持久化删除结果。

#### 3.3.2.4 统计维度与指标

##### 预设维度（建议）

| 维度 | 说明 | 数据来源 |
|------|------|----------|
| 分行 | 按团队分组 | `team_id` |
| 交易码 | 按交易码分组 | `data` 中对应字段 |
| 时间 | 按日/周/月/年 | `created_at`、`updated_at`、`submitted_at` 等 |
| 业务状态 | 按状态分组 | `status`、`approval_status` |
| 台账类型 | 按模板分组 | `template_id` |

##### 自定义维度（扩展）

- 管理人员可选择模板中的任意字段作为统计维度。
- 需考虑字段类型（文本、数值、日期等）对分组与展示的影响。

##### 统计指标（建议）

- 数量：记录数（COUNT）。
- 金额汇总：对数值型字段求和（需指定字段）。
- 其他聚合：平均值、最大值、最小值等（按需扩展）。

#### 3.3.2.5 图表类型

| 类型 | 适用场景 | 说明 |
|------|----------|------|
| 柱状图 | 分类对比 | 横轴为维度值，纵轴为指标值 |
| 折线图 | 趋势分析 | 横轴为时间，纵轴为指标值 |
| 饼图 | 占比分析 | 各维度值的占比 |

#### 3.3.2.6 导出功能

- **入口**：看板右上角「导出」按钮。
- **范围**：当前视图下的所有图表对应的统计数据。
- **格式**：Excel（.xlsx）。
- **内容**：每个图表对应一个 Sheet 或一个区域，包含维度、指标及汇总数据。
- **命名**：建议以「视图名称_导出时间」命名文件。

## 4. 非功能需求

### 4.1 性能

- 列表查询与统计计算需考虑数据量，建议：
  - 分页加载，单页建议 20–50 条。
  - 统计接口支持异步或缓存，避免长时间阻塞。
- 大数据量时考虑：
  - 后台任务生成统计结果。
  - 对常用维度建立索引或物化视图。

### 4.2 权限

- 需新增权限点，例如：
  - `statistics:view`：查看统计与看板
  - `statistics:create`：创建/编辑视图与图表
  - `statistics:export`：导出台表
- 数据权限：统计结果是否受团队/角色数据权限约束，需明确。

### 4.3 兼容性

- 前端需兼容主流浏览器（Chrome、Edge、Safari、Firefox 等）。
- Excel 导出需兼容常见办公软件（如 WPS、Microsoft Excel）。
